# Terra Mage First Scene v0.0.4 - Programmer Asset Request

Programmer AI requests no Blender asset yet. The first scene must use Unity primitives so gameplay can be validated before Creator work.

## Mock Character Requirements

- 30 cm tiny mage scale.
- Chunky cartoon silhouette.
- Primitive body capsule.
- Simple robe/cloak color block.
- Small staff cylinder.
- No final mesh or animation required yet.

## Scene Requirements

- Walkable ground.
- Oversized sandbox blocks/rocks for scale.
- A core marker.
- Camera target/pivot.

## Creator Gate

Creator may start only after Programmer asks for one of these assets to be replaced with authored art.
